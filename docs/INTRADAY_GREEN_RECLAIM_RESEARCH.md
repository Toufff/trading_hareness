# 盘中绿转红与板块共振研究模式

状态：`experimental`，研究与人工复核专用，不发送自动委托。

## 研究问题

把“涨幅较大”拆为三个不同过程，而不是把它们混成一个买入因子：

1. 板块共振领涨：板块净流入、个股主力流、量比和同板块分钟确认同步出现。
2. 绿转红回收：先出现日内低点，价格重新站上 VWAP 和昨收，再以分钟级量价扩张确认。
3. 高开强延续：已经有很大日涨幅的股票只记录为延续/扩张，不能被绿转红规则追入。

## 当前实时研究条件

仅在显式观察池的 `metadata.reversal_research.enabled=true` 时评估。一个研究观察需要同时满足：

- 当前涨幅在 `+0.5%` 至 `+6.5%`，避免把临近涨停的扩张当作入场；
- 三分钟涨幅 `+1.5%` 至 `+4.5%`；
- 当前分钟量至少为前 20 分钟中位数的 3 倍；
- 价格重新位于 VWAP 上方、距日内低点至少反弹 3%；
- 刚刚由绿转红，或已从日内低点回收至少 4%；
- 腾讯全 A 同截面主力净流入位于前 10%，或至少两个已登记同主题 peer 同时确认。

命中后只产生 `watch:green_reclaim_research_v1`。仍需下一次扫描或同板块独立确认，且有十分钟去重；它不是订单，也不替代风险止损。

## 验证路径

今天只有事件回放样本，不能声称任何收益能力。下一步是连续积累至少 60 个交易日的逐分钟事件：使用当时可得的板块快照、腾讯横截面、超级分钟线，按下一交易日开盘/收盘分别计算收益、最大回撤、命中率和行业暴露；达到样本量与样本外门槛前，策略状态保持 `experimental`。
