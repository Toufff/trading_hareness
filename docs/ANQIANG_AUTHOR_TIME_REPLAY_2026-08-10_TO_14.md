# 安强作者时间操作回放（2026-08-10 至 2026-08-14）

## 结论先行

本次回放首次以安强原始事件正文中的日期时间为 `stated_at`，而不是本地补档时间。
这能评价作者观点的**作者时间**，但仍不改变系统实时策略的因果时钟：实时链路只使用
不可变 `received_at`。

本周有 16 条带可信作者时间的消息级操作（8/13 六条、8/14 十条，涉及九只标的）。
本地没有在信号时点五分钟内覆盖这些标的的报价；因此 **0/16 可以做严格的分钟级
成交/收益结算**。不得把日线或延迟观察池报价伪装成盘中成交价。

对 8/13 的六条操作，可做一个较弱的“当日收盘到次日收盘方向延续”检查：持有三条
均为正，减仓三条均为负，合计 3/6、等权签名变动约 -2.32%。这不评价作者当时的
盘中减仓是否卖在高位，只说明它们在收盘后的隔夜延续并不占优。

## 时间与证据规则

| 字段 | 用途 |
| --- | --- |
| `stated_at` | 正文提取的原始事件时间；本报告的作者时间回放基准 |
| `time_evidence.source=remote_content_timestamp` | 表示旧档案由带日期的正文时间恢复；新远端结构化 `stated_at` 优先 |
| `received_at` | 远端不可变接收时间；唯一实时策略可用时间，不可被作者时间回填 |

例如，8/14 的两条原始消息已验证为：`09:50:26`（本地收到 `10:49:59`）与
`10:48:48`（本地收到 `10:49:38`）。两者在本报告中均使用前者。

## 严格分钟级结算：数据门禁未通过

严格口径要求：信号后首个 `tencent_free` 价格必须在五分钟内，并可找到同源 15/30/60
分钟后报价。当前本地 `intraday_quote_observations` 是当时观察池的采集，不是全市场
历史分钟库；上述 16 条均没有合格起点。

为避免扩大成全历史拉取，只尝试了两项定向补数：东财/AKShare 的单标的历史分钟请求
被上游断连；Super GET 的 `rt_min_daily` 定向请求返回 SSL/代理错误。两者都没有作为
收益依据或写入 canonical 数据。

## 8/13 收盘后延续代理（非成交回测）

基准为 8/13 收盘，观察点为 8/14 收盘。方向为正表示持有/买入后上涨，或减仓后下跌。

| 标的 | 操作 | 8/13 收盘→8/14 收盘 | 签名结果 |
| --- | --- | ---: | ---: |
| 宏景科技 | 减仓/出局 | +8.58% | -8.58% |
| 天孚通信 | 减仓 | +4.10% | -4.10% |
| 红板科技 | 持有 | +1.35% | +1.35% |
| 云南锗业 | 持有 | +1.38% | +1.38% |
| 长川科技 | 持有 | +0.48% | +0.48% |
| 致尚科技 | 减仓 | +4.44% | -4.44% |

持有：3/3 正；减仓：0/3 正；合并：3/6 正、等权签名变动 -2.32%。

该结果**不能**推出“减仓判断错误”：减仓的判断是在盘中给出，若盘中已经锁定可观浮盈，
收盘到次日收盘的上涨并不能否定其盘中 T 或风险控制价值。只有补齐同源分钟路径后，
才能计算卖出后的 MFE、回撤规避和实际可交易价格。
