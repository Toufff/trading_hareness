# 板块热度页面重设计与验收

2026-09-09。范围仅为板块热度 UI，未修改评分模型、采集、券商或交易计划。

## 阅读顺序

1. 交易日期和阶段始终显式标注，顶部列出当前类别关注排序前三名，不称为买入推荐。
2. 桌面：左侧行业/概念、搜索、排序和内部滚动榜单；右侧所选板块的状态、涨跌、成交额、大单净额及活跃度。
3. 解释与缺口提示后紧接大图；评分明细、采集时间与全局数据说明折叠。缺口提示仍在主视图，不靠折叠隐藏。
4. 小于 980px 改上下布局，列表限高；手机不重复展示前三名卡片，给详情留空间。

## 真实性约束

- 历史默认只裁掉首尾全部缺失的区段，内部缺值保持 null，禁止跨缺口连线。完整历史窗口可切换。
- 单点可见；分歧线默认关闭，可以点图例打开。分数不是上涨概率。
- 搜索命中数与类别总数分开；行业/概念各 100 个样本不冒充全市场。
- 原有列表/详情独立请求、15 秒超时、取消过期请求、缓存及图表异步加载保留。
- 图表模块和数据请求并行预热，失败由图表自身提示，不影响文字渲染。公网冷加载延迟仍受网络影响，不承诺秒开。
- 不添加新交易判断，不把供应商大单口径解释成机构身份。

## 模块

- SectorHeatPanel.vue：只读请求与交互组合。
- sector-heat-panel.css：隔离的响应式布局。
- sector-heat-presentation.ts：无数据篡改的历史裁边、百分比格式。
- SectorHeatChart.vue：延迟加载图表，不阻断文字。
- SectorHeatView.vue：独立页面入口 /sector-heat。

## 可重复验收

运行前端 typecheck、build 与 SectorHeatPanel / sector-heat-presentation 测试（10 项）。
运行 scripts/verify-sector-heat-ui.mjs，凭据通过 STOCK_DASHBOARD_CREDENTIALS 指向外部文件。
默认测公网；本地通过 SECTOR_HEAT_BASE_URL 指向 Vite、SECTOR_HEAT_API_ORIGIN 指向公网，用真实 API 数据验证，不构造理想行情。

浏览器验收检查：

- 页面启动有内容，真实详情 20 秒内可读；列表与所选详情代码一致。
- 搜索、类别切换、日内/日间、完整历史、折叠证据可用。
- 1440px 桌面图表宽至少 650px、高至少 300px，顶部位于首屏；左右边界对齐。
- 默认栏高小于 1000px，列表内部滚动，防止全部 100 行撑开页面。
- 1920 / 1440 截图和 390px 手机截图人工查看；补测 1280 / 768 / 320px 无横向溢出和画布自适应。
- 模拟图表资源失败，真实列表和因子证据仍可查看。

验收中实际发现并修复了 flex/grid 列表撑高及 768px 画布缩放溢出，已加回归断言。
浏览器结果与截图见 docs/evidence/sector-heat。此验收不能作为全系统、数据完整性或策略收益的通过声明。
