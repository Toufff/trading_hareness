# 分析师文本因子：纯文本归档与共识

状态：`experimental`。分析师文本是研究上下文，不是自动交易指令，也不直接替代价格、成交量、资金流和风险控制。

## 数据范围

截至 2026-08-10，本地已同步远端 **16** 份已完成报告：抖音六子 4 份、郭一鸣 3 份、立伟 4 份、杨宁 5 份，日期覆盖 2026-08-05 至 2026-08-10。同步只请求报告列表和报告详情 JSON 的已提取文本字段：`summary`、`raw_markdown`、`sections`、`predictions`、提及股票/主题及时间元数据。

导入边界由代码强制执行：`materials` 置空、`source_url` 置空、图片 Markdown、视频/音频链接和“完整原文”链接均在落库前移除。同步器不会请求、下载或保存远端图片、视频、音频、上传附件或链接目标。

安强投资日记和全能野人当前远端目录仍为 `report_count=0`，因此不计入本轮因子；新消息已改用远端实际登记 ID，待其首份报告完成后自然进入同一管线。

## 因子定义

| 因子 | 口径 | 防止误用的设计 |
| --- | --- | --- |
| `analyst_market_consensus_3d` | 每位分析师先对自身近 3 日报告做指数衰减，再对分析师投票取均值 | 长报告、重复 OCR 区块不会压过独立分析师。 |
| `analyst_theme_consensus_3d` | 先按“分析师 × 报告 × 主题”折叠主题声明，再跨分析师聚合 | 主题只有单人提及时仅作观察，不视为市场共识。 |
| `analyst_text_freshness_3d` | 报告可得时间的指数衰减平均值 | 新旧观点不会等权；历史报告不倒灌到早期快照。 |

核心半衰期为 3 天。所有因子均保存为点时可得的文本证据；主题/市场因子目前只记录在特征快照与 `/api/v1/analyst-factors`，尚不进入自动订单或强制改变量价策略评分。

## 与盘中策略的结合

分析师因子只能充当第三层确认：

1. **先有市场数据**：超级 Tushare 分钟线的加速、相对量、VWAP、日内新高；腾讯全 A 资金流；东财板块资金。
2. **再有文本一致性**：主题至少两名独立分析师同向且具备足够新鲜度，才提高研究优先级。
3. **最后仍需事件确认**：30 秒扫描的二次确认或同主题 peer 广度；涨幅超过首突破窗口、无量反抽、板块持续流出时，文本观点不得覆盖风险规则。

分析师历史命中率达到足够样本后才可影响权重。当前没有把缺少 scorecard 的观点当作“专家真值”，默认仅用于解释、排序和人工复核。
