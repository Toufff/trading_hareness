# 多尺度量能—资金流研究（2026-08-10 至 2026-08-14）

## 可以做，但必须分层

“量能”和“资金流”不能混成一个数。系统应同时保留：

1. **全市场量能**：成交额、成交量、涨跌家数，定义风险偏好和交易拥挤度；
2. **日内板块轨迹**：一分钟快照的流入广度、流入中位数、早盘/午后/尾盘变化，识别资金轮动发生在何时；
3. **跨日板块状态**：日频概念资金流的持续、反转和价格背离，判断日内动作是延续、派发还是技术性回补；
4. **龙虎榜/涨停热度**：只作为高换手和拥挤风险的补充证据，不能替代资金趋势。

下列结果是上周五个交易日的研究快照。五天不足以形成可交易参数，所有公式应先作为 `research_only` 证据写入，而非改变实时规则阈值。

### 上周量价的关键读法

- **8/12 不是高置信度主升确认**：上涨家数和资金广度高，但总成交额/量连续下降，更像存量资金推动的广度修复。
- **8/13 是最重要的风险状态**：成交额和量同时放大，而上涨家数、概念流入广度同时急降；这比单纯的指数下跌更接近主动卖压释放。
- **8/14 不能直接称为反转**：量能回落 16%，概念流入广度仅 28.2%。科技硬件局部回补存在，但没有出现“放量 + 广度持续转正”的确认。

## 3. 可落地的状态因子

### 市场量能状态 `MVR`

用市场成交额/成交量相对过去 20 个交易日的分位定义扩张或收缩；当前数据深度不足，暂不固定阈值。

| 状态 | 条件示例 | 策略含义 |
| --- | --- | --- |
| 风险扩张 | 量能上升、上涨广度和概念流入广度同时上升 | 允许寻找板块延续，仍需个股确认。 |
| 放量派发 | 量能上升、上涨广度下降、概念流入广度低 | 停止新多头候选，优先风险提醒。 |
| 缩量修复 | 量能下降、广度回升但未过中性 | 只列入次日观察，不给即时追涨加分。 |
| 缩量走弱 | 量能下降、广度继续恶化 | 降低候选数量，等待风险释放。 |

按这个分类，上周 8/13 对应“放量派发”，8/14 对应“缩量修复”。

### 日内资金漂移 `IFD`

`IFD = 尾盘流入广度 - 早盘流入广度`，同时记录午后最低值和尾盘是否收复。它区分“全天趋势”与“尾盘抢修”。

- 8/12：早盘约 50.8%，尾盘 66.1%，为正漂移且中午已扩张；
- 8/13：从可用早段 38.6% 降至 8.2%，为显著负漂移；
- 8/14：早盘 30.1%、午后低至 10.1%、尾盘回至 27.6%，是**尾盘修复**而非日内转强。

实时触发时，应要求概念条目数达到覆盖门槛、连续多个一分钟快照同方向，避免单分钟上游缺口造成假漂移。

### 跨日资金反转 `SFR`

`SFR` 记录昨日/今日概念净额的正负切换，作为次日开盘的候选筛选，而不是买点：

- 前日流出、当日流入：本周样本的次日表现反而偏弱，可能反映短线拥挤；
- 前日流入、当日流出：本周样本后出现反抽更常见，但需要排除放量派发日；
- 因此 `SFR` 必须和 `MVR`、`IFD` 联用，不能单独交易。

### 龙虎榜热度惩罚 `LHB-H`

将龙虎榜拆为“异动原因、换手、净额、所属板块日内/跨日状态”。建议规则：

- 高换手或开板热度叠加板块放量流出：增加兑现风险，拒绝反抽加分；
- 龙虎榜净买入不直接加分；当前可结算样本中，净买入组次日仍偏弱；
- 仅在同源精确成员板块由流出转稳定、个股重回 VWAP 且量能承接时，作为低权重佐证。

## 4. 实时研究链路

```text
全 A 成交额/成交量/涨跌家数
          │
          ├── MVR：风险扩张、放量派发、缩量修复、缩量走弱
          │
东财一分钟板块快照 ── IFD：早盘→午盘→尾盘漂移
          │
Tushare 日频 THS 概念资金流 ── SFR/资金-价格背离
          │
龙虎榜、开板、高换手 ── LHB-H：拥挤与兑现风险
          │
同源精确成员 + 腾讯/超级源个股量价、VWAP
          ↓
仅生成“观察 / 确认 / 风险”证据，人工决定交易
```

## 5. 实施纪律

1. 每分钟保存 `IFD` 原始组成及覆盖率；不要只保存最终排名。
2. 每日收盘保存 `MVR`、`SFR`、龙虎榜可用性、以及未来 1/5 日结果，形成不可变研究样本。
3. 在至少 60 个交易日、200 个独立事件前，所有因子只展示在前端研究页，不改飞书买卖提醒的阈值。
4. 东财日内流与 Tushare 日频流不可直接相加；前者用于盘中方向，后者用于收盘归因和跨日状态。
5. 对接口缺口、板块条目数过低、跨源价格失配必须打质量标记并降级信号。
