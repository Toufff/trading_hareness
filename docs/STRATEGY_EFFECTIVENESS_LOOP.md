# 效果反馈闭环（2026-09-13）

## 合同与验收先行

正式策略不变。收盘后自动读取候选冻结记录，按策略、配置版本、市场状态、来源和可得性分组。
先评价观察表现，再评价可成交的**模拟**交易，二者不可混称实盘收益。

1. `effectiveness/rules.py`：同日头部/后排配对，去重、日期等权、非重叠窗口、覆盖率；异常只作原子待复核事项。
2. `effectiveness/execution.py`：次日开盘入场、持有到预注册窗口收盘、T+1、停牌/涨跌停/缺数据、复权变化、佣金最低额/税费/滑点；缺信息不猜可成交。
3. `effectiveness/experiments.py`：有限注册排序变体，同一资格集合，训练/隔离期/保留集，固定规则不挑事后最佳参数。支持资金弱化、均线偏离惩罚弱化及成交参与排序；只输出影子证据。
4. `effectiveness/service.py`：现有G盘账本读入、内容寻址证据、异常去重入治理池；样本不足有明确数量，失败不阻断当天扫描。
5. 人工推荐用独立CLI登记：真实登记时间、原策略候选范围、选中股票、理由、作者及版本；不允许事后补录伪装为盘前意见，不与机器排名混算。
6. 报告与页面显示效果覆盖、异常、影子对照及等待原因。现有独立reviewer复核原始证据；最终human批准边界保留。影子建议不直接变成生产配置，也不通过任意代码执行模型提案。

## 明确限制

- 默认效果窗口5交易日，诊断阈值及最低独立日期是版本化研究规则，不是回测最优参数。
- 历史重建只能作探索；正式效果验证只接受前瞻冻结、相同版本、完整保留集。窗口重叠不算独立样本。
- 入池表示有证据的疑点，不表示已经证明因果或策略盈利；未触发不表示策略正确。
- 日线无法验证盘中回封/VWAP等条件。模拟次日开盘策略的收益不能替代原文字条件策略收益。
- 任意代码修改仍走常规独立实现/评审/部署。本次不授予自动上线权。

## 必须执行的验收

纯函数反例：重复样本、版本混合、缺数据、历史补录、未来日期、幸存者偏差、前排长期落后、未到期、同日不能卖、涨跌停无法成交、复权跳变、费用、实验范围与保留集泄漏。
真实G盘：当前数据运行、输出来源/数量/不足原因、无正式配置变化；构造失败案例只放隔离测试事务，不污染真实问题池；重复调用不重复入池。
部署后：真实收盘链路、owner/adapter报告读回、前端构建与实际页面；工程通过和效果通过分别报告。

## 自动推进与人工边界

每次正式收盘扫描调用 `effectiveness.pipeline.attach`，该段失败有独立状态与日志，不清空选股。既有收盘调度继续调用独立角色 dispatcher：observer 入原子事项、reviewer 质疑、designer 审查宿主固定提案、implementer 登记影子清单、evaluator 计算未来观测、validator 复验、release_preparer 整理待落地清单。不同角色身份检查沿用治理库。

只扩展 `registered-ranking-effectiveness-v1`，不是任意模型代码执行。支持成交参与、近期强度、均线偏离补偿、资金/横盘排序四个有限假设；它们不改变资格池。均线补偿是额外排序对照，不能冒称已精确识别生产惩罚的因果作用。自动首个提案固定为成交参与对照，不从历史收益中挑表现最好的变体。

正式实验从登记后的日期开始，最长两年，同版本/策略/市场状态/来源；最低20个非重叠五日日期、100个观察。验证净改善、净收益、日期胜出比例、覆盖率和不利波动，净改善另有按日期标准误构造的保守下界；这些仍不是盈利保证。历史探索用训练/隔离/保留段，但不作为前瞻通过。样本积累可能需要数月；版本修改时旧实验不能继续拼样本。

人工建议登记：`scripts/record-manual-recommendation.py --scan <本轮JSON> --lane <策略key> --symbols <带交易所代码,逗号分隔> --author <作者> --reason <当时理由>`。完整比较池冻结，只给所选股票加标记。周末登记使用真实周末日期、下一交易日开始跟踪，不伪装成周五已提出的意见；不自动挖聊天记录追认。

复验入口：`scripts/inspect-effectiveness.py --date YYYY-MM-DD` 只读；`scripts/verify-effectiveness-live.py` 使用真实G盘连接，合成异常及角色流转均在外层事务回滚；`scripts/verify-effectiveness-deployment.py --baseline` 留排名基线，部署后 `--run` 重跑并比对三层API与十份报告。`frontend/e2e/effectiveness-live.spec.ts` 需显式 `RUN_EFFECTIVENESS_UI_LIVE=1`，只读验证公网。
