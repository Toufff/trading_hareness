# 盘中扫描统一实现与验收（2026-09-14）

## 边界

一个入口、九套正式策略、独立于持仓；只新增盘中适配，不变更已批准权重、不下单。盘中结果不能写进已结算日线。策略匹配、证据可用性、前瞻价格计划、可成交性分别记录。历史结果永不被收盘结论覆盖。

## 模块

1. source：同日 Longhu 全市场窗口，单批不超过300；候选公平补充分钟与80日真实OHLC。
2. engine：复用九策略核心与治理配置；半日累计额只作下界，缩量需要可比较证据。潜伏允许平台内承接，不要求先突破。
3. runner/repository：冻结输入、实现指纹、运行阶段、九报告与结果读回；失败保留具体阶段。
4. reconciliation：原计划之后的价格触发与收盘变化，不反推成交或收益；新增对照记录，不改原扫描。
5. HTTP/UI：读取同一运行ID，独立页面、策略切换、候选依据、分时和结构线、缺口和对照。GET不触发扫描。

## 时间与证据

市场窗口时间、OHLC采集时间、最终可知时间分别展示。盘中日K是采集时的未完成日K，不是此前窗口的历史日K；禁止收盘后补当天完整日K来回放14:50。冻结回放不联网。收盘后15:00窗口可用于闭市初始化，但不能声称已在收盘前发出建议。日线缩量收盘前未确认，同刻量能缺失明确未知，不线性放大成全天预测。

## 验收目标

- 纯函数：九策略、原候选保留、潜伏不强制突破、日期/重复/覆盖/未来数据拦截、冻结参数和结果哈希、失败与零匹配区分。
- 实际数据：全市场覆盖；补充真实OHLC与分钟；运行ID、输入和报告读回一致；15:00初始化不倒签。
- 闭环：对今天原14:50冻结快照做收盘对照，原文件哈希不变；价格观察不包装成实盘收益。
- 网页：本地和公网HTTP同轮；可切换策略、查看实际分时和结构线；错误/无运行/加载状态独立。
- 回归与部署：后台、前端测试和生产读取；不把测试通过称为盈利验证，也不声称已验证下一交易日定时执行。
