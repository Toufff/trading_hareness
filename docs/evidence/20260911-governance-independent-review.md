# 独立审查：策略治理与量价修复

时间：2026-09-11。审查者 governance_ui 未实施被审查的治理后端或量价规则。以下为修复前发现，不表示最终验收。

## 尚须修复并复验

- GOV-R01：`repository._latest/rollback` 将初始版本视为空排序因子。若首次启用前环境已有非空正式配置，回退0不会恢复原配置。要求保存真实初始有效配置，做非空基线→启用→回退逐字段比较。
- GOV-R02：`approval_config` 仅检查治理 generation，没有核对当前部署代码哈希。排队期间发布了另一代码版本仍可接受旧批准。要求与真实生效代码/配置基线绑定，改变后重新验证。
- GOV-R03：`claim_work` 的 evaluator 只领取 experiment 状态；证据不足后进入 observing，评价者不能再次领取，而 validator 可能重复领取无法通过的任务。要求按新证据版本与样本成熟状态分流，保留旧观察并避免空转。
- GOV-R04：原子范围是 scope/out_of_scope 自由文本，未强制核对实际配置差异。要求结构化变更路径/策略范围，越界变化拒绝，不能用“只修改启动”的问题单影响全部策略。
- GOV-R05：日期只做字符串比较，独立交易日不真实。纯函数实测：两日仅为周末2026-09-05/06时比较仍passed；日期2026-09-01-not-a-date/02-not-a-date同样passed。要求严格日期解析与交易日资格，或明确限制为非交易意义的日期计数，不能宣称样本已足够。

## 证据真实性边界
