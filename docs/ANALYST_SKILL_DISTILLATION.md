# 分析师语言技能蒸馏与提示词实验

状态：`research-only`。本模块从已归档的纯文本报告提炼“表达方式、条件性、风险偏好和显式操作结构”，不创建订单，不改变盘中提醒阈值，也不让模型在没有验收前自动更新。

## 两条不能混淆的时间轴

每条分析师动作保存两种时间：

- `stated_at`：作者在原文中声明的盘中时间，只用于历史复盘。
- `available_at`：量化服务实际收到该报告的时间，只能用它做点时因子和未来验证。

若晚间收到一份含有上午消息的汇编报告，上午动作可以用于研究“当时若看见会怎样”，但绝不能倒灌为上午已知信息。这样的记录标为 `replay_only`，不参与分析师权重或实时信号。

## 每位分析师的技能卡

`GET /api/v1/analyst-skills` 返回每位分析师最新的：

- 文本方向词、条件词比例和报告数量；
- 已解析的动作类型分布、显式价格条件与独立标的数量；
- 点时可用与仅复盘样本的数量；
- 三个固定提示词契约的覆盖度。

当前提示词实验包含：`strict_action_v1`、`scenario_context_v1` 与 `risk_first_v1`。它们是版本化的实验合约；未来接入语言模型时，每个版本必须对同一份、同一知识截止时间的文本生成独立候选，再与相同的结果账本比较。

## 离线 RL / 提示词比较

这里的“RL”是离线 contextual-bandit 式的 `context → extraction/prompt variant → settled reward` 评估，而不是开盘时在线学习：

1. 固定报告版本、原文哈希、`available_at` 与提示词版本。
2. 各变体只输出结构化候选和证据位置，不能直接给交易指令。
3. 收盘后按同一可交易价格路径计算覆盖率、精确性、方向收益、最大不利波动与风险调整收益。
4. 至少 **200** 个成熟动作、跨 **60** 个交易日，且人工审核通过，才允许将某提示词变体标为可复核；仍不自动改写实时规则。

没有可信的实时接收时刻、精确标的或可交易价格路径的内容只保留为语言/市场背景，不进入奖励函数。

## 安强的特殊解析

安强目前的归档含多个作者声明的盘中时间段。系统只使用人工审查过的简称映射，并把 `加仓做T`、`持股`、`减仓`、`接回`、`关注` 分开记录。无法唯一映射的简称不会猜测代码。

复盘接口：`GET /api/v1/analysts/anqiang/trade-actions?as_of_date=YYYY-MM-DD`。若观察池中有同日保存的腾讯秒级行情，返回同日后续收益；没有时只返回日线级或待市场数据状态，绝不伪造分钟回放。
