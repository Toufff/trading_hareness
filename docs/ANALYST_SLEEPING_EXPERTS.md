# 分析师观点：点时结算与 Sleeping Experts

分析师文本是研究证据，不是订单。系统不会抓取远端图片、音频或视频，只接收远端已提取的文本。

## 时间边界

- `remote_published_at` 保存远端的发布时间/编辑时间，仅用于延迟诊断。
- `first_synced_at` 与版本 `first_seen_at` 是唯一可用于结算的可用时点；报表后续修订不会回写为更早可用。
- 作者在文中写出的盘中时刻仅用于复盘。若本地收到该版本晚于作者时刻五分钟以上，该动作和观点标为 `replay_only`。

## 观点与收益

系统先把同一分析师在同一本地可用日、同一主题/个股/市场范围内的重复文本折叠为一条观点。主题仅能经已审核的 `analyst_theme_board_aliases` 映射到板块，并使用 `sector_membership_history` 的点时成员构造等权篮子；未映射主题不会猜测归属。

所有收益从观点可用日之后的首个交易日开始，输出 1、2、3、5、10、20、40、60 日的原始、基准与残差收益。等权基准先行，IC 的显著性按交易日聚类；没有足够样本时明确显示为 `research_only`。

## 等权验证与专家聚合

在任意加权之前，系统先输出等权基线：逐观点命中率和残差收益、按观点可用日聚类的 IC 标准误、八个期限的 CAR 曲线、首个 CAR 走弱期限、分析师 top/rest 分层，以及受众规模交互诊断。没有正向且按日期聚类显著的 IC，状态为 `stop_or_collect`，不会推进为模型权重。

受众规模和独立/推广属性不会从收益中倒推；它们只能经人工溯源录入 `/api/v1/analyst-research/profiles/{analyst_id}`，保留来源说明和观察时点。未录入时明确显示为不可用。

## 专家聚合

采用非平稳 Sleeping Experts + Fixed-Share，而非 RL / bandit：

```text
S_i <- 0.99 * S_i + reward_i (仅该日发声者加入奖励；休眠者只折现)
w_i <- (1 - 0.01) * softmax(0.4 * S_i) + 0.01 / active_count
输出再按 T_eff / (T_eff + 100) 向等权收缩
```

奖励是方向残差收益经已实现篮子波动率标准化，再减去同一结算日横截面均值并截断到 `[-1,1]`。单票在数据充分时使用同产业、同市值三分位同日基准；主题和大盘退回广义市场基准，方法被写入 outcome 元数据。

固定默认参数不会被小样本调优。只有 walk-forward 明确胜过等权且有足够交易日时，状态才可能进入人工复核；当前与所有后续早期样本均不影响盘中提醒或买卖策略。条件化选择会按预先定义的市场状态、范围、期限出报告；成对排序仅对相同日期/期限的匹配样本比较。这两种方法在至少 5,000 条已结算点时结果前保持禁用。
