# 可拆装排序因子

2026-09-11。因子不是第十个策略，不改九策略匹配规则，不自动授予买入权限。

## 使用方式

默认关闭。不设置 `QUANT_SHORT_TERM_FACTOR_PROFILE`，且单次运行不传 `--factor-profile`，保持原策略排序。

用户说“这次横盘加小盘偏好”时，为**单次运行**提供配置；没有明确持续启用要求，不写入生产环境变量。不得因为一次请求永久改变全部策略。

```json
{
  "version": 1,
  "factors": [
    {"key": "small_cap", "enabled": true, "weight": 0.12,
     "strategies": ["accumulation", "pullback"]}
  ]
}
```

`strategies`可指定九策略任意组合；`["*"]`代表全部。参考模板：`config/examples/small-cap-factor.json`。

已加载本机runtime.env时：

```powershell
cd G:\StockPlatform\current\quant-service
..\.venv\Scripts\python.exe -m app.short_term_lanes.service --date 2026-09-10 --factor-profile ..\config\examples\small-cap-factor.json --output-dir G:\StockPlatform\reports\factor-variants\2026-09-10-small-cap
```

`--no-factors`明确关闭所有附加因子，优先于环境配置。单次带因子的CLI输出必须放独立目录，不能覆盖正式报告目录；它不会将该变体冒充数据库中正式发布的轮次。

确需持续启用时，生产build读取 `QUANT_SHORT_TERM_FACTOR_PROFILE` 指向的配置路径，生成结果的settings、因子版本、参考总体哈希与报告正文一起落库。运行中的服务修改环境变量需按正式部署流程重启；不可声称修改文件即已生效。网页只展示已发布轮次的配置与排名，不在浏览器私自改排序；本次未新增浏览器配置开关。

## small_cap定义（2026-09-11细化：市值区间偏好）

- 用户偏好总市值约100—600亿元，并非声称整个区间在市场通用分类中都属小盘。保留`small_cap`配置键，版本升级为`size-preference-soft-band-2026-09-11`；旧报告保留旧版本，不改写历史分数。
- `total_mv`（元）是评分轴：100—600亿元得100分；低于100或高于600时，以到最近边界的倍数距离d=log2(边界/市值)或log2(市值/边界)，得分=100×2^(-d²)。50/1200亿元得50分，98.24亿元约99.95分。不是硬过滤，也不是越微盘越好。
- `circ_mv`普通流通市值保留展示与数据质量核对，不再奖励极低流通比例，不能冒称自由流通市值。
- 同日主板参考总体的市值分位保留作解释，不参与得分；避免大量不活跃微盘股改变用户目标区间的偏好分。100—600和倍数衰减是明确的初始用户偏好参数，不是收益最优参数。
- 同日两个市值均为正、有限值，流通不高于总市值（仅1%容差），至少20只有效参考且覆盖率至少80%。单股缺数据不加分；全体覆盖不足整项跳过，保留原策略结果并解释。
- 默认加分预算12分：`调整后分数 = 原策略含活跃度分数 + 0.12 × 小盘得分 × 原风险路由倍率`。这是辅助加分，不是12%的收益预测，也不重算/削弱原成交活跃评分。
- 只在同策略、同风险状态内比较。风险状态、成交额门槛、形态匹配、行业限额、入场/失效条件均不变；风险观察不得转成优先买入。
- 同时保留原始分数与排名、调整后分数与排名、因子加分、实际市值、分位、数据覆盖、版本及证据哈希。排名是行业限额/展示截断前的同风险状态匹配排名，不等于网页展示顺位。
- 小盘因子不会改变高级策略最多96只OHLC预筛范围；它只在现有匹配之后排序。未纳入预筛的股票不会凭市值加分进入高级策略。

这些初始权重、封顶点和覆盖阈值是工程/研究参数，未经样本外收益优化。新因子扩展 `app/ranking_factors` 的独立纯函数和注册表，不向策略条件函数或main.py塞判断。

## 验证

`scripts/verify-ranking-factors-live.py`读取正式G盘数据库（连接强制只读），一次补充OHLC后复用同一输入，比较：默认关闭、指定策略启用、全部启用、再次关闭。报告写独立验收目录，检查匹配数量不变、未指定策略逐字段不变、关闭恢复、市值覆盖、十份报告读回一致。

这不证明因子有超额收益，不验证其他自动任务，也不重新定义盘中数据为收盘数据。
