# 盘中首突破量价资金共振研究

状态：`experimental`。只生成研究级 `watch` 事件，要求人工复核及下一次扫描/板块独立确认；不会提交委托。

## 为什么不只用一个指标

2026-08-10 的强势个股并非都来自同一种走势：北方长龙属于开盘后持续走强，湖南黄金体现贵金属尾盘资金扩张，翔鹭钨业属于午后首次突破，而有研新材在高涨幅后的放量只能归类为延续。因此，单看涨幅、量比或主力净流入都会引入大量晚到信号。

新规则只研究“仍在可控涨幅窗内的第一次日内高点突破”，同时要求以下因子共现：

| 因子 | 实时定义 | 作用 |
| --- | --- | --- |
| 日内涨幅窗 | `+1.0%` 至 `+6.5%` | 排除近涨停扩张和弱势噪声。 |
| 短窗加速 | 1 分钟至少 `+0.25%`，3 分钟 `+1.2%` 至 `+3.5%` | 捕捉启动而非缓慢漂移。 |
| 分钟相对量 | 当前分钟成交量至少为前 20 分钟中位数 `2.5` 倍 | 约束“有价格、没成交”的假突破。 |
| VWAP 位置 | 高于因果 VWAP `0.2%` 至 `5.5%` | 买盘需在当日平均成交成本上方。 |
| 首次新高 | 当前价格不低于此前已出现的日内高点 | 仅用当前分钟前的高点，避免未来函数。 |
| 资金或板块确认 | 腾讯全 A 主力净流入分位前 20%，或已登记 peer 中至少 2 只、占比至少 66% 同步确认 | 降低孤立拉升的误判。 |
| 日线趋势 | 收盘前可得的 MA5/MA20 多头只增加 4 分，不是硬门槛 | 允许反包，同时避免让旧趋势压倒盘中事实。 |

## 评分与分型

核心项（短窗加速、相对量、VWAP、新高、资金/peer）必须全部成立；基础分达到 76 才能成为候选。日线趋势和日内区间上部位置只用于排序。收盘涨幅超过 `+6.5%` 一律拒绝为首突破，改交由“强延续/异常扩张”风险观察处理。

## 数据与验证

分钟量价优先采用已验证的超级 Tushare `rt_min` 近 30 根窗口；腾讯分钟线作为同主题 peer 广度的独立补充，腾讯全 A 快照提供同一时刻资金流分位，东财板块流用于 2--5 分钟级别的板块确认。任一源失败会被记录为缺失，不会以另一源的收盘值伪造盘中指标。

至少积累 60 个交易日事件后，按 5/15/30 分钟与次日收益、最大不利波动、涨跌停可成交性、换手和行业暴露进行滚动样本外检验；在此之前，阈值和分数都只是可证伪的研究假设。
