# 分析师消息的点时边界

远端分析师档案服务 `0.3.22` 的消息详情已接入本地研究服务。消息与日报是两个独立证据源，不将其伪装为报告，也不读取远端图片、音频或视频；仅保存详情 API 已返回的 `content` 文本。

| 字段 | 本地用途 |
| --- | --- |
| `received_at` / `strategy_available_at` | 唯一的策略、学习与结算可用时间；两者必须相等且不可变。 |
| `published_at`、`edited_at` | 来源时效/编辑追溯，不决定策略可用性。 |
| `stated_at`、`time_evidence` | 作者或 OCR 可见时间的复盘证据；不会回填为盘中可用时间。 |

同步工作流每 15 分钟读取每位分析师最新 100 条消息摘要，首次运行只建立 `received_at` 水位，不导入旧消息；后续只请求水位以后的详情并按 `message_id` 幂等导入。每个详情仍受本地写鉴权保护。

安强的明确买卖动作会进入独立的复盘账本，保留 `stated_at`，但其 `available_at` 固定等于远端不可变的 `received_at`。消息观点同样进入 `analyst_claims`，由既有的点时结算与研究门禁处理；它们仍是研究证据，未跨过样本门槛前不会影响实时交易策略。
