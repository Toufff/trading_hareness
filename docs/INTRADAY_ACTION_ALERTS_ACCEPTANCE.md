## 明确未完成的上线条件

1. **正式运行时/存储接线未完成。** 当前是可测试影子实现，尚无正式PostgreSQL动作状态适配与单一运行时注册，不能声称现有飞书循环已开始调用它。
2. **当前五只股票计划覆盖不完整。** 依顿、焦点、华天、博敏缺对应计划；彤程只有旧新买计划。预览彤程遇到下移原止损拒绝，不可绕过；博敏遇到凌晨计划日期语义问题，不可删质量门凑覆盖。
3. **账户费用、整手规则、分钟参数及成交绑定需要正式证据接入。** 纯规则显式输入不等于生产已经配置；手续费不得用fixture的测试值。
4. **真实历史点时回放、真实盘中影子、六类卡真实显示与投递验收未完成。** 单测测试数据不构成这些证据。

因此部署判定为否，不能只等开盘就宣称自动可用。继续施工时先完成第1～3项，再以真实时点验证第4项；总体验收通过后才允许走正式发布脚本。不得降低原止损、伪造首腿成交或删除质量门来变绿。
