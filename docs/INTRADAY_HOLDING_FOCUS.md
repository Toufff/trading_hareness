# 持仓盘中重点监控（2026-09-23）

## 定位

所有经核实的持仓继续获得原有的盘中重要变化、纪律与固定简报。用户可从“我的持仓 → 盘中重点监控”手动标记某只持仓为当日 `intraday_t` 重点。标记不改变报价采集频率、固定简报时间或普通行情异动的推送门槛；只让已有卡片和简报在有有效证据时补充该股的分钟技术状态。不是交易授权，不下单，不修改推荐池或纪律线。

标记必须属于账户最近一份 `verified_exact` 且仍在有效期内的持仓快照。标记在上海时间当日 15:05 自动失效，可随时取消。快照之后的新增成交、成本、可卖数量仍为未知；尤其不能用昨日的可卖数量推断今日的 T 操作能力。

## 数据与规则

`quant.intraday_holding_focus` 仅保存账户、证券、意图与到期时点；不保存交易指令。运行时每轮重新加载持仓和有效标记，停止持仓或到期后不再纳入重点。前端经适配器的操作者 Key 写入；量化服务仍执行持仓校验。

正式分钟源为 Longhu `GetStockTrendIncremental` 的已完成分钟行。先通过现有 `validate_minute_tape` 严格校验交易日、时间顺序、连续性、午休与新鲜度，然后至少需要 60 根已完成分钟收盘价。每 60 秒至多拉取一次每只重点持仓，不阻塞原有五秒报价采样；单股分钟源失败只将该股技术状态标为不可用。

- 标准分时 MACD 柱：`DIF=EMA12(close)-EMA26(close)`，`DEA=EMA9(DIF)`，`2×(DIF-DEA)`；这不是用户自定义同花顺公式的自动识别。
- Wilder RSI14、20 分钟收盘价布林带、最近 3 分钟价格变化、最近 15 分钟收盘价区间、3 分钟成交额速率相对此前 20 分钟中位数、供应商会话 VWAP。
- 买方/卖方“共同确认”需要价格位于 VWAP 正确一侧、MACD 柱连续 3 根朝同方向、RSI 未进入明显极端、3 分钟价格变化绝对值至少 0.3%、成交额速率至少 1.3 倍。它只描述量价与动量一致，不是 B/S 点。
- 15 分钟区间幅度不超过 0.55%、3 分钟成交额速率不高于 0.85 倍且 MACD 柱接近零时标记“持续横盘且量能收缩”。
- 真正的分钟高低价不存在于该数据源，因此绝不计算或宣称分钟 KDJ、ATR、ADX。委比继续只是折叠的挂单辅助证据，不参与多空投票。

盘中重要变化卡原有触发与节流不变。若同股同时被标记且分钟数据新鲜，卡片会增加技术证据块；固定简报与十分钟条件检查可把有实质变化的重点状态纳入评估，但没有变化必须静默。数据断档/过期不是多空反转，不得由此发状态变化卡。模型不得凭单一指标、盘口挂单或昨日期货式可卖数量生成确定 B/S、回补价格或收益承诺。

## 接口与验收

- `GET /api/v1/intraday/advisory/focus?account_key=citics-primary`：当前快照中的持仓及标记状态。
- `PUT /api/v1/intraday/advisory/focus/{symbol}?account_key=...`：标记当日重点，必须有有效核实持仓。
- `DELETE /api/v1/intraday/advisory/focus/{symbol}?account_key=...`：取消标记。
- 对外页面代理为 `/api/research/intraday/advisory/focus`；写入需 `X-Dashboard-Key`，由适配器转交量化服务。
- `GET /api/v1/intraday/advisory/status` 的 `details.manual_focus_count` 和 `details.focus_technical_status` 用于运行检查。

测试：`test_intraday_holding_focus.py` 覆盖标记/到期/持仓限制、指标边界、横盘、缺失数据与卡片；原压力、通知策略及前端页面测试回归。发布后先只读核对接口、运行状态和页面，再实际标记 `002315.SZ` 并读回；开盘时才可能核对分钟证据。无同日真实成交与费用数据时，本功能保持“重点观察”，不宣称收益优先的实际 T 买卖点已经上线。
